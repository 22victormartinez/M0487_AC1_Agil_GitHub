# Guía rápida de Metodologías Ágiles y GitHub

Actividad AC1 del módulo M0487 - Entorns de desenvolupament (1º DAW).

En este repositorio hemos hecho una guia rapida sobre metodologias agiles y como trabajar con GitHub usando un tablero Kanban y Pull Requests.

## Como hemos trabajado

1. Hemos creado un GitHub Project tipo Kanban con las columnas To Do, In Progress, Review y Done.
2. Cada seccion es una issue asignada a un miembro del equipo.
3. Cada uno ha trabajado en su rama y ha abierto una Pull Request.
4. Un compañero revisa la PR, deja un comentario y hace el merge.
