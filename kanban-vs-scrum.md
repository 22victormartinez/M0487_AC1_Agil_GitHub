# Diferencias entre Kanban y Scrum

Kanban y Scrum son dos metodologias agiles. Las dos se usan para organizar el trabajo del equipo pero funcionan de forma distinta.

## Que es Kanban

Kanban es un tablero con columnas (por ejemplo To Do, In Progress, Review, Done) donde se van moviendo las tarjetas de las tareas segun el estado en el que estan. Viene de Toyota, lo usaban en las fabricas para controlar la produccion.

Lo mas importante en Kanban es limitar el trabajo en curso (WIP), o sea que no puede haber muchas tareas a la vez en la misma columna para no saturarse.

## Que es Scrum

Scrum divide el trabajo en sprints de tiempo fijo y tiene roles y reuniones concretas (ver la seccion de conceptos de Scrum).

## Tabla comparativa

| | Kanban | Scrum |
|---|---|---|
| Tiempo | Flujo continuo, no hay sprints | Sprints de 1 a 4 semanas |
| Roles | No tiene roles obligatorios | Product Owner, Scrum Master y equipo |
| Reuniones | No son obligatorias | Planning, Daily, Review y Retrospective |
| Cambios | Se pueden añadir tareas en cualquier momento | No se cambia el sprint una vez empezado |
| Tablero | Es lo principal | Se puede usar pero no es obligatorio |
| Entregas | Cuando una tarea esta acabada se entrega | Al final de cada sprint |

## Cual usar

Kanban es mas flexible y va bien para equipos pequeños o para mantenimiento donde van llegando tareas todo el rato. Scrum es mas estructurado y va mejor para proyectos mas grandes donde hace falta planificar.

En esta actividad hemos usado un tablero Kanban pero con roles de Scrum (Scrum Master), asi que es un poco una mezcla de los dos.
